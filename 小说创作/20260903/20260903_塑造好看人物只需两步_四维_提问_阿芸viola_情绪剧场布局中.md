## 🎯 核心提炼版

### 第一步：人物四维塑造法

用四个维度搭建基础人物框架：

1. **外部性格**：人物对外展现的性格特征
2. **内部性格**：人物内心真实的性格状态
3. **秘密**：人物不为人知的过往经历
4. **物品**：对人物有特殊意义的物件

**案例示范**（24岁女孩）：
- **外部**：直率、激灵
- **内部**：每次上台/演讲都会紧张
- **秘密**：高中上台演讲出糗，被所有人嘲笑
- **物品**：一个奖杯（曾获很多奖，但唯独这个奖没得到，一直是年级第一）

### 第二步：问无关紧要的问题（由外向内提问）

**⚠️ 常见误区**：提问方向过于单一，导致人物变得**狭窄**。

**错误示范**（全部指向"海边/自由"）：
- 下班后去哪 → 人少的地方 → 海边
- 社交平台昵称 → 自由的海浪
- 不做教师想做什么 → 旅游相关
- 离开城市去哪 → 南方海边

**问题**：所有答案都指向同一个意象，人物会变得非常狭窄。现实中一个人不可能只有"海边"这一个追求。

**✅ 正确做法**：发散提问，不设限，第一感觉回答，不考虑与之前答案的关联。

**正确示范**（发散提问后的人物补充）：
- 养宠物吗？→ 不养，觉得是束缚
- 谈过几段恋爱？→ 两段（大学一段、工作一段），目前单身
- 分手原因？→ 耗费心神、时间
- 什么让他放松？→ 听歌、看展
- 有交心的朋友吗？→ 有，是放松状态下认识的陌生人
- 从小到大有好朋友吗？→ 小时候有，工作后渐行渐远
- 有巨大愿望吗？→ 想上太空，因为那里没有人

**效果**：人物气质自然浮现——**文艺、清冷、短发**，真实感大幅提升。

### 核心逻辑

- 只有基础四维 → 故事会变得**假**、**直线化**（比如"战胜演讲恐惧"这种老套情节）
- 加上发散提问 → 人物有血有肉，故事更真实
- 方法总结：**人物塑造147问**（在临级数学课程中）

## 💡 关键要点总结

1. **四维塑造法**：外部 + 内部 + 秘密 + 物品，搭建人物骨架
2. **提问法**：问无关紧要的问题，由外向内逐步深入
3. **避免单一化**：提问时不要被已有答案带偏，保持发散
4. **真实感来源**：人物要有多个生活面向，不能只有一条故事线
5. **落地工具**：人物塑造147问（课程中提供）

---

## 🛠️ 实践建议

1. **先搭骨架**：用四维塑造法快速建立人物基础档案
2. **再添血肉**：围绕人物进行发散式提问，每次至少问10个以上"无关紧要"的问题
3. **警惕同质化**：如果连续3个答案都指向同一意象，立刻切换提问方向
4. **记录第一反应**：提问时要求自己凭直觉回答，不要理性推演
5. **检验真实感**：尝试给人物匹配现实中的演员，如果找不到对应人选，说明人物还不够立体

## 📜 完整内容精排版

塑造一个好看的人物只需要两步。

**第一步**，用人物四维塑造法，分别是他的外部，加他的内部，加他的秘密，以及加一个物品。

举个例子，一个女孩，他大概24岁。他的外部性格是非常的直率，非常的激灵。那内部性格呢，实际上他每一次上奖台或者是去演讲的时候，他都会有一点紧张。他的秘密是，他曾经在高中的时候上台演讲，结果出糗了，导致所有的人都嘲笑他。而他的物品呢，是一个奖杯，曾经得过很多奖，但是这个奖没有得到，他一直都是年级第一的这样一个人。

但是光塑造完这个，不好看。我们还需要**第二步**，问一些无关紧要的问题，而这些问题可以从外向内地去问。

比如说，我先问一个比较外层的问题：如果这样一个人，他下了班，在这个城市里面想去一个地方，你觉得他会去哪？我觉得他会去人少的地方吧。比如这个人会找一个人少的地方。为什么？去哪干嘛呢？安静啊。特别疯了什么呢？他觉得自己待着，没人打扰他，日落也挺好。

好的好的，我开始由外向内去问了。那如果他有一个社交平台，请问他社交平台上的昵称叫什么名字呢？这个有点难想。学辩地什么都行，可能就是一些什么海浪啊、月亮那种好符号，但没有那种具体文字，自由的海浪，可以大概就这个意思，自由的海浪。

好，我继续问了。如果他现在有机会可以不做他现在这样一个职业，我给他职业设定成教师。如果他不做教师，他可以选择做别的职业，你觉得他最想做什么？我觉得他可能会做旅游相关，因为他都叫自由了。你问，你问，嗯，旅游相关的那。

继续问：如果他现在能够离开这个城市，去任何一个地方，你觉得他去哪儿？为什么？我觉得他可能会去南方的海边。那他就是一个北方人，去哪儿干什么呢？就是想看看大海，感受感受这种和自己一直想见，在这种海浪见一面的感觉。

现在我们问的所有的问题，你全都慢慢地滑向一个具体的人。对，这不是不好，而是会容易让你的故事写小。什么意思呢？我刚刚问了很多个问题，我问了他会去哪儿，你告诉我去河边；我问了他昵称，你告诉我是海浪；职业是旅游；为什么会去这个地方，你告诉我是南方的海边。其实这说到底都是同样一个意思。而你给我这些答案的旅游，全部都在于你已经锚定了一个海、一个自由，往下去想的。这样想不是不对，而是如果我们写的是长篇小说，这个人物会变得非常的狭窄。但正常情况下，我们一个人，比如我，比如你，我们是很想去海边，但我们会从小到大，现在30多岁、40多岁，就只纠结一件事情，只有一个东西叫做海边吗？不可能，对不对？我还有自己的朋友，我有自己的亲人，我有自己的同事，我有自己喜欢的东西，所以我的人生世界不是只有海边的。这样想会让他越来越狭窄。

那我们再做一个练习，还是继续去问问题。我还是会问一些无关紧要的问题，请你第一感觉给我回答，不用考虑和这个海边有没有联系。

他有没有宠物？没有。想不想养宠物？不想。为什么？觉得会束缚他。所以他觉得关系对他来说是束缚吗？对。

我继续想想，问他谈过几段恋爱？两段。大学当中和毕业之后一个，工作当中一个。工作那他现在单身还是恋爱？单身。为什么分手呢？也是因为工作。大学的时候是因为工作调动，工作的时候为什么分手呢？觉得应付不过来。他觉得这都是一个耗费心神的事。明白，就是时间问题，耗费心力的。

他能做什么事情让他无比的放松？随便说，第一印象。听歌，看展。听歌看展。

如果他有一个无话不谈的朋友，你觉得这个朋友是一个真实存在的人，还是一个什么其他东西？我觉得可能是一个真实的人。那真实的人，他是什么情况下认识的这个朋友？就是放松的状态下认识的，听歌看展这个场景下，一个陌生人，然后成为了朋友。

那他从小到大有没有好朋友？小时候有，但是工作了就淡了。

他有没有巨大的愿望？他想上太空。为什么？我就觉得那里有没有人，有自由。很棒很棒。

现在你问的这些问题，会让他变得很好看。首先我们看到这样一个基础的人物：一个女生，24岁，他是教师，他非常的直率激灵，上台之前会紧张，秘密就是因为他曾经出糗，而他的物品是曾经得了很多的奖状。这么一个人，而且他是一个北方人。你其实会从他的秘密和物品推出来很多他的具体的情节。什么情节？这个情节要解决他曾经觉得这个事情无比重要。

仅看这个蓝色的框，你能推出他是一个什么气质的人吗？或者说他大概长什么样子？你有这个感觉吗？拼不出来。

那我们继续来往下看，你刚刚给我补充了很多其他的东西。来看这里：他不养宠物，因为他怕被关系束缚；他曾经恋爱过，但是觉得太耗费时间和心力了；他喜欢自己一个人听歌看展；能交心的好朋友，还是一个这几年刚认识的一个陌生人；而他从小到大是有好朋友的，只不过随着他慢慢变大，尤其是在他高中的时候，就再也没有结交好朋友了；而且这个人就想上太空，因为太空里没有人。

当你有了这样一些无关紧要的问题之后，你会发现这个人的气质出来了。他是一个很文艺的人，他身边有点清冷。不是那种拒人于千里之外的文艺，长发飘飘，还不是那种清冷，他有可能是一种短发。而这些东西和上面加起来，会让这个人物变得有真人感，脑子里大概有个模样了。你现在就算找我们当下的演员给他对应上来，哪个人能够演绎这个角色，你能找到一个差不多的。

这样问一些无关紧要的问题还有一个好处。来看情景：如果我只有蓝色框，那我讲的情节是不是他又得来一次演讲，他最后战胜了自己？但这个人物或者说这个故事，是不是有点太假了，或者太直线了？好像这个人的人生就除了高中演讲这件事情之外，就没有其他重要的事情了。但你如果问了一些无关紧要的问题，你会在他成长人物弧光的过程当中，去讨论他还能听歌看展，他还能跟他的陌生朋友聊天，他还想去外太空。而这些东西加起来，会让这个人物无比真实，也就让你的故事不假了。

所以塑造人物就两步，再总结一下：

**第一步**，用人物四维坐标轴塑造一个基础的人物。
**第二步**，问一些无关紧要的问题。

所以我才总结了**人物塑造147问**，这个在我的临级数学的课程包里。而这两个方法能让你的人物，首先他的剧情不扁平，而且人物很真实。

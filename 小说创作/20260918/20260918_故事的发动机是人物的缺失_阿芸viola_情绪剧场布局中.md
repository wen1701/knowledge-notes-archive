## 🎯 核心提炼版

### 一、核心命题

- **故事的发动机不是情节，而是人物的缺失**。
- 这是**韩国编剧金太元**提出并讲过的理论。
- 他讲：**每一个故事里的角色，内心里都有一个"洞"，这个"洞"就是他的缺失**。

### 二、从"缺失"到"情节"的推导链条

| 环节 | 内容 |
| --- | --- |
| ① 起点 | 人物内心有一个缺失（一个洞） |
| ② 驱动 | 一旦内心有缺失，他就**必须做点什么去（弥补）** |
| ③ 行动 | 他"做什么"这件事本身，就是人物的行动 |
| ④ 结果 | 这个行动就**形成了故事的情节** |

**一句话链条：缺失 → 必须做点什么 → 行动 → 情节。**

### 三、与"人物维度"理论的呼应

- 这和之前讲过的**人物三維、四維、五維**是同一回事。
- 人物要有：
  - **外在**
  - **内在**
  - **核心**
- 人物会**通过核心延展出一些行动**，而这个行动就是**你故事的情节**。

### 四、为什么很多人"想不出情节"？

- 很多人在开始创作时，会觉得**情节很难想**。
- 如果写故事时你**还需要费心力去想情节**，说明：
  - ❌ 你**没有做好人物塑造**
  - ✅ 你只做了**人物的设定**
- **人物设定**很难让你自然地发展出情节；
- **只有进行人物塑造**——像前面说的，给角色**设置一个内心的洞、设置一个缺失**——
  - 人物就会**自然而然地产生行动**；
  - 这个行动就能让你**自然而然地想出情节**；
  - 而且这个情节还**不生硬、不突兀，也不是突发和偶然事件**。

### 五、两个必须注意的雷区

**1. 缺失不能太简单（太轻）**

- 反例：设计一个主角**想考第一名，但考了第二名**。
- 这样的缺失**太轻**。
- 一旦缺失太轻，**观众就不会信任你的故事**。

**2. 缺失不能让观众感觉不到（太抽象）**

- 反例：设置一个主角**特别害怕被抛弃**。
- "害怕被抛弃"是一个**非常抽象的概念**。
- 你需要把它变成**可以具象化的镜头或者画面**：
  - 比如她害怕被抛弃，那她对待现在的男朋友（或女朋友）会产生什么行动呢？
  - 她可能会**查看他的手机**；
  - 或者会**让他发定位**。
- 而这些都是**具体的情节**以及**具体呈现的画面**。

## 💡 关键要点总结

- **发动机换了**：不是"我想写一个什么情节"，而是"我的人物缺什么"。
- **缺失 = 洞 = 驱动力**：有洞就必须填，填的过程就是情节。
- **设定 ≠ 塑造**：设定只给标签，塑造才给"缺失"，缺失才自动生成行动。
- **好情节的三个特征**：不生硬、不突兀、不是突发偶然事件。
- **缺失两条红线**：不能太轻（观众不信）、不能太虚（观众看不见）。
- **终极结论**：不会想情节、不会写故事？**先去塑造人物，先去给人物塑造一个缺失**——这个方法非常好用。

## 🛠️ 实践建议

1. **写故事前，先写一句"人物缺失句"**
   格式：这个主角最缺 ______，因为 ______。
   例：主角最缺"被确认自己值得被爱"，因为他从小被寄养。

2. **审查缺失的"重量"**
   自问：这个缺失如果永远得不到，人物的人生会崩塌吗？
   如果答案是"也还好"，那就是"考了第二名"级别的轻缺失，必须加重。

3. **把抽象缺失翻译成"身体动作"**
   公式：抽象情绪 → 具体行为 → 可拍摄的画面。
   "怕被抛弃" → "查手机 / 要发定位" → 镜头：深夜解锁对方手机。
   凡是你写不出画面的缺失，都还只是概念，不是情节原料。

4. **用"行动推导表"反推情节**
   缺失 → 他会做什么 → 谁阻止他 → 冲突 → 情节。
   每写一个行动，就当一段情节直接用，不要另起炉灶硬编。

5. **自查清单（写完大纲后逐条过）**
   - [ ] 主角的缺失能用一句话说清吗？
   - [ ] 这个缺失足够重，重到必须行动吗？
   - [ ] 这个缺失能被拍成一个具体的画面吗？
   - [ ] 我现在的情节，是从缺失推出来的，还是我从外面硬塞进去的？

6. **卡情节时不要硬想情节**
   回到人物身上改设置：加缺失、加重缺失、把缺失具象化。**人物一改，情节自来。**

## 📜 完整内容精排版

故事的發動機不是情節，而是人物的缺失。這是韓國編劇金太元講過的一個理論，他講每一個故事以的角色內心裡都有一個動，這個動就是他的缺失，而他一旦內心有缺失，他就必須做點什麼去離譜，而他做什麼的這件事情就形成了故事的情節。

這也和我們之前講過的人物三為四為五為是一樣的，人物要有外在、內在，一起核心，他會通過核心去演展出一些行動，而這個行動就是你故事的情節。

有些人在開始創作的時候會覺得情節很難想，如果大家在想故事的時候，你還需要去廢心力想情節，說明你沒有做好人物塑造，你只做了人物的設定，而人物的設定是很難讓你自然然發展情節的。你只有進行人物塑造，就像剛剛說的，我們給人物角色設置一個內心的動，設置一個缺失，這樣人物就會自然而然地去產生行動，這個行動就能讓你去自然而然地想出情節，而且這個情節還不聲硬、不突兀，也不是突發和偶然事件。

只不過要注意幾個事情：首先，你設置的這個人物內心的缺失，它不能太簡單。比如說我設計了一個主角，它想考第一名，但是考了第二名，這個缺失就太輕了，而一旦缺失太輕，觀眾就會不信任你的故事。

同樣，你設置的這個角色內心的缺失不能讓觀眾感覺不到。比如說我要設置一個主角，它特別害怕被拋棄，害怕被拋棄這是一個非常抽象的概念，你需要把它變成一個可以巨像化的鏡頭或者畫面。比如它害怕被拋棄，那它對待它現在的男朋友或者女朋友會產生什麼樣的行動呢？它可能會查看它的手機，或者會讓它發定位，而這些都是具體的情節以及具體呈現的畫面。

所以如果不會像情節，如果不會像故事，先去塑造人物，先去給人物塑造一個缺失，這個方法非常好用。

## 🎯 核心提炼版

### 一、人物关系图的搭建方法

**第一步：确定主角，居中放置**
- 把主角放在关系图的正中间。本案例中主角是**徐福**。
- 为什么？因为他是主角。

**第二步：把配角围绕主角展开**
本案例的配角包括：
- **俊生**（陈俊生）
- **塞夫**（那个小孩）
- **老扎**（餐厅老板）
- **老板的女儿**
- **老板的妈妈**

**第三步：在每个角色旁边列出其特性**

| 角色 | 特性 |
| --- | --- |
| **徐福** | 厨师的性格、大大咧咧、欠债、有点蛮不靠谱的感觉（这是他一开始给人的感觉） |
| **俊生** | 感觉什么都会、很全能的一个人，但也有点圆滑、爱撒谎和胆小 |
| **塞夫** | 有战争过往；他的核心秘密是——遇到战争他一定都很有关系 |
| **老扎** | 餐厅老板，比较有地位，是一个小头小领导，后面会有关于这个国家的故事（不然为什么给他设置这个国家某一个职位呢，他可以交代背景，一定有用） |
| **女儿和妈妈** | 放在这里是为了讲徐福的故事和背景 |

### 二、梳理人物彼此之间的关系

- **女儿和妈妈 ↔ 徐福**：后期有点是那种超越好朋友、更好一点的关系。首先他不是帮助的关系，也不是阻碍的关系，而是成为了一个**目的**或者说一个**原因**——正是因为我的妈妈和我的女儿他们在家里需要钱，我才需要出来。
- **俊生 ↔ 徐福**：一开始是合作伙伴，但后面已经因为战争成为生死之交了，他们才是互相帮助以及好朋友之间的关系。
- **徐福 ↔ 塞夫**：从小流氓小坏蛋变成了他的徒弟，师徒上升到父子。觉得塞夫其实是一个徐福的缩小版吗？也是一个如果不受管教、没有人去带着他引领他往前走的话，他也会变成一个可能会很坏的人。
- **老扎 ↔ 徐福**：从老板变成股东和贵人，再变成了可以夺走他生命的人，但这个人的底色还是朋友，因为他们立场不同。

### 三、核心阻碍：战争

"我发现我这几条线全是朋友，我一定会有一个更大的阻碍，那阻碍是什么？**战争**。"

- 战争一出来，我不需要再给战争这个阻碍多匹配一些其他的人了，因为战争足够庞大。
- 战争是一个很具有命运感的东西，无论我们谁经历过战争，你其实都无法逃脱。
- 只是因为战争一出现，会导致这些人彼此之间现在画的这个颜色的人物关系会变化：
  - 战争一出现，老扎从朋友、从他的股东、从他的老板，变成了一个可能会夺走他生命的一个人，变成了一个好像是站在他对面的一个人。
  - 战争一出现，塞夫从一个正常的一个小孩子，变成了一个可能会拿枪去报仇的一个人。

### 四、填充彼此之间的剧情

**原则**：不要去想概念和很抽象的东西，把它变成实实在在的剧情。

- **俊生 ↔ 徐福**：之间的剧情已经列出来了，包括女儿跟徐福之间的原因和目的也已经列出来了。
- **俊生 ↔ 老扎**：他们之间一定有故事，而且这个故事一定是跟徐福相关，他们是造成徐福这种遭遇的最直接的两个人之一。
  - 为什么能够彼此联系？因为老扎缺厨师，俊生会中国话，于是他们俩之间需要有合作。
  - 俊生帮徐福来做翻译，老扎还答应了俊生"我之后给你股份"，结果中间被徐福给拦下来了，俊生才会跟徐福闹一出。
  - 所以这些是他会拥有的情节。
- **俊生 ↔ 塞夫**：塞夫不是他女朋友那个孤儿院的小孩吗？这其实塞夫在一定程度上帮助你塑造了俊生的人物，俊生的背景，他让俊生有点立体起来了。
  - 如果塞夫不是俊生女朋友那个孤儿院的孩子的话，你会觉得塞夫出现在这个场景里面是有点偶然的。这种突发事件和偶然事件不好看。
  - 明明你的角色能有很多作用，帮助你去塑造其他角色，所以我们一定要把故事想好。
  - 他们俩之间就会除了有背景故事之外，还会有其他的故事，毕竟只是在故事的前半段就会讲明白。
- **俊生 ↔ 塞夫（战乱发生之后）**：
  - 俊生死掉那一段，俊生死掉之前那一段，按照徐福的逻辑，他是一个能忍则忍的人，知道我能救几个人我就救几个人，我不会为了救更多的人导致这些人的生命全都结束。
  - 但俊生不是这样的人，俊生会救所有的孩子。为什么？因为他的女朋友就是孤儿院的老师，他从小就看这帮孩子们长大，他能不救吗？在他的角色层面上，他绝对会救。
  - 那他怎么会救？他有拉着徐福，他有一段戏，他靠在墙边看着塞夫笑，然后孩子们在旁边吃着涂涂（食物）。其实你能从这段戏当中知道俊生一定做了点什么，不然他不会前一秒孩子跟徐福说"我们要把所有人带走"，后一秒他就坐在这里跟塞夫说"他们吃了多香啊，等咱们一块逃出去的时候"。
  - 他会说这些话，那说明其实他已经做了一些什么，而这段戏就是徐福比俊生还给塞夫了一个可乐。俊生最后还是死掉了。
  - 所以他这几个情节安排的特别的巧妙，又有伏笔，又给后面埋下了一些情绪爆发的一个种子。
- **塞夫妈妈和女儿 ↔ 徐福**：
  - 看起来好像没有联系，但是他们之前绝对有联系，我觉得有一点点情感的投射在里边。
  - 对，没错，谁的情感投射？徐福。没错，徐福因为在国外我看不到自己的女儿，我也是为了我女儿出来的，我要挣钱。
  - 但现在我遇到了塞夫，我会不会把她当作我的孩子来对待？当她做错事的时候，我会不会像真的父亲一样去制止她？
  - 她说"师父"的"师"是老师，"父"是父亲，你把我当"编"（伴）？其实她是一种情感投射。
  - 这个妈妈和女儿找不到徐福的消息的时候，是因为战争，而这种战争是不是塞夫一直就经历了？所以这种妈妈和女儿这种交集的状态，其实我们也侧面（反映）塞夫这种人物这种战争孤儿在战争的阴影之下是活得多么的痛苦。
- **老扎 ↔ 塞夫**：
  - 看起来好像没联系，但一定有联系。要说去情绪上，我就想到了他们做那个婚宴，塞夫也是一个比较合格的厨子。
  - 其实他们俩重点不在这儿，而是塞夫其实和老扎是一个国家的人，他们是不是经历同样的事情？但是两个人走向了不同的选择。
  - 而这个不同的选择是因为徐福。徐福跟老扎的交情不深，我没有办法帮老扎，我顶多是给她（做点事）位于范张张嘴。
  - 这是徐福跟老扎之间的故事，所以老扎最后变成了一个极端分子。
  - 如果说徐福没有参与塞夫的人生的话，塞夫是不是也变成了极端分子？塞夫有一条线就是她一直想复仇、一直想复仇、一直想复仇，而徐福在中间拦着。
  - 所以其实你会发现，老扎和塞夫看起来他没有彼此聊天的剧情，但是徐福因为在中间，就会挡着这两个人的人生走向不同的道路。
- **老扎 ↔ 妈妈和女儿**：
  - 虽然变不成剧情，但他对故事很有用。老扎和妈妈还有女儿看起来好像也没有联系，我觉得有一些吧。
  - 徐福也有妈妈和女儿，老扎等于在去世的时候……所以她能知道她有多难受，而且这同样还是两个对比。
  - 老扎是经过战争之后支离破碎，她变成了极端分子；而妈妈和女儿生活在和平的地方，这也是一个情感上的对比。

### 五、还需要写其他人物

- 除了写这些人物，故事不能完整的，我们还需要写一些其他人物，比如说**功能型的人物**，比如说**背景人物**，比如说这些配角周围的人物。
- 老扎周围有女儿、有妻子；俊生旁边还有她爱的人、还有那些孤儿；塞夫周围还有那帮小朋友；还有校长。
- 这些权（全部）都是配角，所以你需要把他们单独的人物关系图可以试着去列一下，这样你就会有更多的剧情了。

### 六、回应"过度解读"

- 会不会有点太过渡解读了呢？这个事情大家要这样看：
  - 如果你懂创作、懂故事的方法论，你会在这种解读的过程当中去巩固你的方法论，帮助你的创作。
  - 但如果你故事的几乎（基础）也不懂，我自己也没有创作的能力，那你确实叫过度解读。
- 我们最终的目的是要写一个完整的故事，而不需要解读别人的作品。
- 学习优秀的作品的经验，我们才能写得越来越好。

## 💡 关键要点总结

- 人物关系图：主角居中，配角环绕，每人旁边先列特性，再连线梳理关系。
- 关系类型要区分：帮助关系、阻碍关系、目的/原因关系、镜像/投射关系。
- 故事的驱动力来自一个足够庞大的外部阻碍——本案例中是"战争"。
- 战争一出现，人物关系自动翻转，无需再为阻碍另配角色。
- 配角的剧情要落到"实实在在的剧情"，不要停留在抽象概念。
- 每个配角都要有塑造其他角色的功能，避免偶然、突兀的出场。
- 用伏笔（如俊生那场戏）埋下后续情绪爆发的种子。
- 记得补充功能型人物、背景人物及配角周围的独立人物关系图。

## 🛠️ 实践建议

1. **画出你的故事人物关系图**：中间写主角，四周写配角，每个角色旁标注 2-3 个核心特性。
2. **逐对连线**：列出每一对人物之间的关系类型（帮助/阻碍/目的/投射/对照），用不同颜色标注立场变化。
3. **设定一个足够大的外部阻碍**：当阻碍出现时，检查哪些人物关系会自动翻转，无需额外新增人物。
4. **把抽象关系转成具体剧情**：对每对有联系的角色，写出至少一个"可拍摄"的场景或事件。
5. **为每个配角设定功能**：问自己"这个角色如果不出现，故事会缺什么？"如果答不上来，就重新设计。
6. **埋下伏笔与情绪种子**：在故事前半段安排看似日常的对话或动作，为后半段爆发做铺垫。
7. **补充功能角色**：为每个主要配角再画一张独立关系图，延伸出更多剧情可能性。
8. **巩固方法论而非过度解读**：解读优秀作品时，始终围绕"我能学到什么可复用的方法"这一目标。

## 📜 完整内容精排版

我们是着用人物关系图分析一下龙餐馆。首先我们要先把龙餐馆里面的人列出来，为什么中间要花一个徐服呢？因为他是主角，而我会把其他的配角画在他的旁边。配角有陈俊生、将亲名、试验的曬夫、那个小孩、老渣，是他老板，是他餐厅的老板，以及他的女儿和他的妈妈。

首先我们要在每一个角色的旁边列出他的特性，比如说徐服的特性是什么？除时性格呢大的莉莉，然后他欠债，有点那种蛮不靠谱的感觉，这是他一开始给人的感觉。来俊生感觉什么都会，很全能一个人，但也有点与安好对严谎和胆小。来再来曬夫，他是一个战争过往，那么他的特性和特点，他有一个核心的秘密就是遇到战争他一定都很有关系。还有老渣，是他餐厅的老板，而且还是一个比较有地位的一个人，因为也是一个小头小领导，所以他在后面也会有一些关于这个国家的故事，不然为什么给他设置这个国家某一个指位呢？他可以交代背景，对一定有用。还有他的女儿和妈妈，为什么放女儿和妈妈呢？讲徐服的故事和背景。

我们把周围的人列出来了，接下来去看一件事情，他们彼此之间的关系。女儿和妈妈对于徐服来说是一种什么样之间的关系？后期有点是那种超越好朋友更好一点的关系，首先他不是帮助的关系，他也不是阻碍的关系，他是成为了一个目的或者说一个原因，正是因为我的妈妈和我的女儿他们在家里需要钱，我才需要出来。俊生和徐服一开始是合作伙伴，但后面已经因为战争成为生死之角了，他们才是互相帮助以及好朋友之间的关系。来徐服和曬夫从小溜芒小坏蛋变成了他的图地失图，上升到父子，觉得曬夫其实是一个徐服的缩小板吗？也是一个如果不受管教，没有人去带着他引领他往前走的话，他也会变成一个可能会很坏的人。老扎对于他来说，从老板变成古东和惠人，再变成了可以多多他生命的人，但是这个人的底色还是朋友，因为他们立场不同。

我发现我这几条线全是朋友，我一定会有一个更大的阻碍，那阻碍是什么？战争。对这个阻碍是战争，而且你会发现战争一出来，我不需要再给战争这个阻碍多匹配一些其他的人了，因为战争足够捧大，战争是一个很具有命运感，无论我们谁经历过战争，你其实都无法逃脱，只是因为战争一出现会导致这些人彼此之间我现在画的这个颜色的人物关系会变化。战争一出现，老扎从朋友、从他的古东、从他的老板变成了一个可能会多多他生命的一个人，变成了一个好像是站在他对面的一个人。战争一出现，彩服从一个正常的一个小孩子变成了一个可能会拿枪去报仇的一个人。

然后我们要做这样一个事情了，找彼此之间的剧情。首先俊生和徐服之间的剧情其实在这儿我都已经列出来了，包括女儿跟徐服之间他的原因和目的我都已经列出来了。我还需要做一件事情，你觉得黑绝之间又没有什么彼此可以联系的剧情，我先把俊生和老扎画在一块，他们之间一定有故事，而且这个故事一定是跟徐服相关，他们是造成徐服这种遭遇的最直接的两个人之一。但是我们要从剧情来讲，大家在用人物关系图创作故事的时候，最好用的就是能创作出剧情，所以我们不要去想概念和很抽象的东西，把他变成十大时的剧情来。老扎和俊生为什么能够彼此联系？是因为老扎缺处是变生会中国化，于是他们俩之间需要有合作，俊生帮徐服来做翻译。老扎还答应了俊生物之前给你骨份，结果中间被徐服给拦下来了，俊生才会跟徐服闹一处，所以这些是他会拥有的情节。

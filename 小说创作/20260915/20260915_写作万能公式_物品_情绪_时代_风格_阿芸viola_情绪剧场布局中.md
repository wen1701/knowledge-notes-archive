## 🎯 核心提炼版

### 一、万能公式

**一个物品 + 一个情绪 + 一个时代 + 一个风格（类型）= 一个好故事**

作者原话："一个物品加上一个情绪，再加上一个时代，我就应该能想出一个好故事。这次可以再加一个东西——照着你的类型。"

### 二、公式四要素拆解

- **物品**：故事的锚点与线索载体（植物、古董、湖露……），它可以是主角身边的东西，也可以与主角命运直接相关。
- **情绪**：人物的内在驱动力（担忧、贫穷、焦虑……），情绪要能落到具体的人身上。
- **时代**：**必须给一个具体的时间**，不能笼统说"现在"。
  - 反例：说"现在"，对方会问"最近五六年吗？"
  - 正例："我现在处在1989年，我此刻当下的现在是不是现在？"——**具体年份才是时代**。
- **风格（类型）**：像选电影一样先锚定题材——洗剧片（喜剧片）、科幻片、文艺片、悬疑片、现实主义……**风格决定故事往哪走**。

### 三、三组实战推演案例

#### 案例一：文艺片方向

| 要素 | 内容 |
|---|---|
| 物品 | 胡路（植物） |
| 情绪 | 担忧（生病） |
| 时代 | 现在（AI时代） |
| 风格 | 文艺片 |

**推导过程**：
- 胡路是植物 → 会不会有人众？他一天跟我的主角相关 → 这可能是我主角众的东西。
- 担忧 + 生病 → 主角能不能趋势（去世）了？
- 时代锚定"现在" + AI → **AI能不能复活他？**
- 风格是文艺片 → 可以走 **AI 的视角**去讲他，那么清自己是真人还是掉了；也可以走 **真人视角**，为了这个趋势的人从心（重新）做了一个 AI。
- 联想：**老照片修复**——让趋势的人在动起来。这只是其中一种。

#### 案例二：悬疑片方向

| 要素 | 内容 |
|---|---|
| 物品 | 古董 |
| 情绪 | 上班、上学的担忧 |
| 时代 | 2020年 |
| 风格 | 悬疑（选移） |

**推导过程**：
- 古董值钱吧？值钱，老值钱了。**怎么样让它更悬一点？** → 因为他丢了，或者因为某一个人死掉了，它才悬起来。
- 捡到古董的人会不会担忧？孩子可能是捡到这个红露的人，造成这个问题产生；孩子还有可能变成他需要这笔钱的一个问题。
- 核心冲突：**这个人拿到了红露，等于他背后有一堆人在追杀他**，想要这个红露，而他自己也不明白这红露到底值钱在哪。
- 反转：孩子把它当成一个很无聊的摆架，把自己的一个小红露跟这个红露换了 → 追杀的这帮人拿到的是假红露 → **这又很《疯狂的石头》**。
- 参考：泰国惊悚片——贩卖小孩的会把他们藏到湖露里边运走，有工艺品的湖露。

#### 案例三：现实主义方向

| 要素 | 内容 |
|---|---|
| 物品 | 湖露 |
| 情绪 | 爷爷奶奶的担忧 + 贫穷 |
| 时代 | 当下（买房、直播） |
| 风格 | 现实主义 |

**推导过程**：
- 爷爷奶奶是一个手艺人，在湖露上做手艺，其实不挣钱。
- **爷爷奶奶的担忧**：哎呀，这个手艺穿不下去了。
- **小孩的担忧**：做这个不挣钱啊，我的人生现在已经一品如喜（一贫如洗）了。
- **买房**是主角目前的冲突点：因为买房所以需要钱，因为钱就会跟爷爷奶奶产生**两种方向**——
  1. 把这个湖露变得越来越差劲；
  2. 把这个湖露卖得越来越好。
- 两种都可以，然后在这个过程当中再去想情节。
- **与当下结合**：什么直播呀——手艺人靠线上把自己盘火，打出一套成熟的商业模式，就可以派成（拍成）纪录片。

### 四、心法提醒

- **不是让你把这三个元素联起来造剧**，而是要找它们之间的**关联**。
- 物品要能"跟我的主角相关"，成为主角身边的东西。
- 情绪要具体到某个人：谁在担忧？担忧什么？
- 时代给具体年份，风格先锚定，故事自然有方向。

## 💡 关键要点总结

- 公式：**物品 + 情绪 + 时代 + 风格**，四者缺一不可。
- 时代必须**具体到年份**，"现在"不是时代。
- 风格（类型）先行锚定，等于给故事定调：文艺、悬疑、现实主义，走向完全不同。
- 元素之间要找**关联**，不是硬拼凑。
- 物品可以承载反转（真假古董）、承载情感（手艺传承）、承载科技（AI复活）。
- 情绪要落到具体人物身上，形成**冲突点**（如买房需要钱）。
- 最后一步：把故事**和当下结合**（直播、AI、老照片修复），商业性与现实感都出来了。

## 🛠️ 实践建议

1. **随手抽卡练习**：随机写下一个物品、一个情绪、一个具体年份、一个类型，四张卡摆开，强制自己连线成故事。
2. **时代具体化**：每次写"现在"时，逼自己改成具体年份（1989、2020、2026），故事质感立刻不同。
3. **先定类型再写**：像选电影一样先选"文艺片/悬疑片/现实主义"，避免写着写着跑偏。
4. **找关联而非拼接**：问自己"这个物品为什么会出现在主角身边？"、"这个情绪是谁的？"，让元素自然咬合。
5. **制造反转**：物品可以真假互换（假古董）、可以承载生死（AI复活逝者）、可以承载传承（老手艺）。
6. **落地当下元素**：把直播、AI、老照片修复等当代事物嵌进故事，既新鲜又有共鸣。
7. **两种方向法**：当主角面临金钱冲突时，给他两条相反的路（把东西做差 / 把东西卖好），情节自然分叉。

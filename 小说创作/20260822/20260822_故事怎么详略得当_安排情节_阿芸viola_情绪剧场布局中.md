## 🎯 核心提炼版

### 一、核心目标
**详略得当 = 让故事能够删繁就简**，让叙事节奏既紧凑又符合读者的观看逻辑，让读者觉得舒服。

### 二、方法论：两步法

#### 第一步：删情节
- **删除标准**：这个情节是否推动了**主人公发生改变**（性格 / 选择 / 行动）。
- **判断方法**：逐个情节问自己，“删掉它，人物是否有变化？”
  - 没有造成人物转变 → **删掉**
  - 造成了转变 → **保留**
- 做完“删”之后，文章变得简洁，但**简洁≠好看**，还需控制节奏的快慢。

#### 第二步：合并场景
- **核心原则**：把**三个场景 / 四个场景合并到一个场景**，全部讲完。
- **场景选择**：选择**事件权重最大、最有冲突感**的场景作为主舞台。

### 三、案例拆解：20万手术费的故事

**原始三场景（逻辑通顺但节奏散）**

1. **医院**：医生告知爸爸生病，需要 20 万手术费。
2. **家中**：为借钱给朋友打电话，借不到。
3. **公司**：发现公司有一笔钱，可以偷偷转到自己卡上，纠结转不转。

**合并后的单场景（主舞台定在公司）**

1. **工位（发现钱）** → 想转钱 → 看到桌上的**病例单** → 通过“回忆”交代医院场景（爸爸生病需 20 万）。
2. **茶水间（借不到钱）** → 用 **通话记录 + 微信被删** 证明昨天借钱多次被拒，不用回忆（避免与前面回忆重复），情绪跌入谷底。
3. **回到工位（抉择）** → 手放鼠标上，转 or 不转，故事走向下个环节。

### 四、合并场景的三大技巧

- **用物品触发回忆**：病历单 → 自然带出医院场景，避免生硬切换。
- **用道具/行动代替回忆**：通话记录、微信被删 → 演示借钱失败，避免连续两个回忆导致单调。
- **情绪要有曲线**：犹豫 → 谷底 → 抉择，让单场景内的情绪有起伏。

## 💡 关键要点总结

1. **删情节的唯一标准**：是否造成人物性格/选择/行动的转变，没有就删。
2. **简洁不等于好看**：删完还要调整节奏，让结构符合观众的阅读心理。
3. **合并场景的逻辑**：多个场景服务于同一事件、同一目标时，尽量合并到最有冲突感的一个场景中。
4. **用回忆带前情**：回忆要由物品（病历单、照片等）触发，自然顺滑。
5. **避免连续回忆**：第二个场景优先用动作、道具、对话来呈现，防止雷同。
6. **单场景里的情绪起伏**：场景内情绪要有高低曲线，故事才好看。

## 🛠️ 实践建议

1. **写完初稿后**：逐段判断每个情节是否导致人物产生变化，将无关情节大胆删掉。
2. **列出场景清单**：把故事的所有场景列出来，检查是否有多个场景能在同一地点、同一时间内完成；若能，果断合并。
3. **选定主舞台**：优先选择冲突最强、信息量最大的场景作为主场景，将其他场景的信息“搬运”进来。
4. **给回忆找个“触发器”**：用物品（单据、手机、照片等）自然引发回忆，而非突兀直达。
5. **避免回忆扎堆**：第二个及之后的“旧信息”，改用动作、道具、播报、聊天记录等方式呈现。
6. **检查情绪曲线**：合并后的单场景要形成“起→伏→抉择”的节奏，拒绝平铺直叙。

## 📜 完整内容精排版

故事怎么样详略得当，其实就两步。首先，详略得当的核心意思是让我的故事能够删繁就简。那这两步也很简单。

首先，**第一步**：你需要删什么？删的叫做情节。那删情节它有一个标准了。首先，这个情节它必须要推动我的主人公发生性格或者选择或者行动上的改变，这才是一个有用的情节。所以判断这个情节是否能删的标准就是它是否造成我的人物转变。如果没有，把这个情节删掉；如果有，就保留。

当你做完了第一步删之后，你就会发现你的文章已经变得很简洁了。但简洁并不代表着好看。我们详略得当还有一个要求，得让它的这种快慢或者这种看情节的节奏也符合观众平常观看的逻辑，这样它才能舒服。如果它一直看一个节奏非常快情节的一个故事，它也觉得不舒服；或者看一个非常慢的，那我觉得很无聊。

那我们删完之后叫做**第二步**。第二步叫做合并。怎么合并？有一个原则：看看你故事当中能不能把三个场景、四个场景合并到一个场景，全部都讲完。听起来有一点点复杂，但是我给大家举个例子大家就能明白了。

我的第一个情节在医院。为什么在医院呢？因为我的医生跟我说你爸爸生病了，它需要二十万的手术费。我的第二个情节呢，就来到了家里。来家里干嘛呢？我是为了借钱，于是我给朋友打电话，但是我借不到钱。第三个情节，第二天我来到了公司，我发现公司里有一笔钱，而这笔钱我现在刚好可以转到我自己的卡上，没有人发现。那我到底是转还是不转？

其实在故事的逻辑上没有问题，每一个情节都有用，都造成了人物情绪的转变。那我能不能试着把这三个场景全部都写到一个场景里？可以啊。首先这个场景大家会定哪个场景？你可以定医院吗？可以定家吗？你肯定是公司。为什么？因为公司它这个事件是一个很重要的事件，所以我定的就是公司。

那我在这个场景里我就要开始写了。我首先我来到了公司，我发现了有一笔钱，这笔钱呢我想转，观众看到这儿不知道你为什么想转，接下来你就可以写在医院的故事了。而且在医院的故事怎么写呢？我要写我的回忆，通过什么东西来回忆的呢？通过物品，什么物品？一个病例单。我在想转钱的时候发现了这个病例单子，这个病例单子写着我爸生病了，于是我就回想起在医院医生跟我说你爸需要二十万，合理吗？合理。然后我又跳转到现在在公司的这个场景。我到底是转还是不转？我把手放在了鼠标上，我有点犹豫，我最终还是没有转，于是我来到了茶水间。

我来到茶水间干什么？我还有一个情节没写。大家看这里，我还有一个家的情节没有写啊，我要把家的情节加到茶水间里。有人就要说了，哎，我加到茶水间里可以啊，我能不能还用一个回忆来写呢？可以是可以，但是不好看呀。我有两个回忆了，所以我不要又回忆了。我就是现在在茶水间发生了一个事。能有什么事呢？我在茶水间依旧给我朋友打电话，但是我要突显的不是我跟他借钱，而是我昨天晚上已经跟他借了很多钱了，已经跟他通过很多电话了。所以我要通过我的电话的通话记录证明我给他打过很多次电话了，而且我还要证明我打过就都没有接。一个是我就会给他发微信，我就会跟他说，我说那个非常——我说这话挺不好意思的，我也知道你困难，我希望你把钱借给我，如果没有也没有关系。结果我把微信发出去，他把我删了。是不是这个情节就能证明我昨天已经很讨好他了？他把我删了之后，我的情绪现在到哪里了？我已经跌入谷底了，我没办法了。

于是我又回到了这个公司，我的这个工位前面，把手放在我的鼠标上。现在我转钱还是不转钱？你可以看你怎么写了。我**可以**把钱转走，故事就进入到了下一个环节；我也**可以**把钱不转，故事又进入到了我怎么样再去找钱的环节。而我现在写的所有东西全部都发生在公司一个场景，而这个场景它就是一个合集，它很满，而且它的情绪也会有曲线——相比于这个，好看太多了。所以，这就是怎么样让故事详略得当、删繁就简的两个原则：**先删，再合并**。

## 🎯 核心提炼版

### 一、案例背景
- **甲方类型**：阿胶品牌
- **项目需求**：制作广告片，需**受品**（受众认可），并能在**各短视频平台传播**

### 二、方法论拆解：故事联想四步法

#### 第一步：品牌联想
- 从"阿胶"联想到：**吃的** → **古法** → **传承** → **贵气/贵族**
- 核心逻辑：从品牌属性出发，逐层发散关键词

#### 第二步：传播形式联想
- 从"短视频传播"联想到：**短剧**
- 创意决策：将广告片拍成**短剧形式**，适配短视频平台传播

#### 第三步：故事设定联想
- **时代设定**：古代（匹配"古法""贵族"）
- **人物设定**：从"后宫嫔妃"调整为**古代普通人（宫女）**——因为观众无法与嫔妃共情，但能与普通人共情
- **冲突升级**：加入**现代职场打工人穿越重生**元素（匹配短剧热门题材）
  - 故事线：现代职场人穿越回古代 → 仍是打工人（宫女） → 决定"夺回失去的一切"（时间、美貌） → 发现阿胶是解决方案

#### 第四步：商业价值延伸
- 将单支广告片升级为**系列短剧**（"重生系列"）
- 打造**品牌IP人物**，持续产出内容
- 提升**客单价**与**业务量**

### 三、核心结论
> 无论写广告、宣传片还是活动创意策划，**故事方法论是通用的**

## 💡 关键要点总结

1. **联想链条**：品牌 → 关键词 → 传播形式 → 故事设定 → 商业延伸
2. **共情原则**：主角必须是观众能共情的"普通人"，而非高高在上的角色
3. **借势思维**：借用短剧热门题材（重生、穿越、职场）降低传播门槛
4. **长线思维**：单支广告可升级为系列IP，实现持续传播与商业变现

## 🛠️ 实践建议

1. **做品牌联想练习**：拿到任何品牌，先写下你能联想到的5-10个关键词，再从中筛选有故事潜力的词
2. **锁定共情对象**：故事主角优先选择"普通人"视角，避免贵族、精英等距离感角色
3. **借势热门题材**：研究目标平台的热门内容形式（如短剧、重生、穿越），将其嫁接到品牌故事中
4. **设计系列化方案**：提案时主动提供"系列化"方案，既能增强客户粘性，也能提升客单价
5. **跨场景复用**：将故事联想方法论应用于广告文案、宣传片、活动策划等多种场景

## 📜 完整内容精排版

用故事的联想练习，分析我曾经做过的一个广告片。

这次我的甲方是一个阿胶品牌，他想要做一个广告片。但是他对这个广告也有要求：首先他要受品，他想在各个短视频平台上面去传播。我怎么样用故事的联想的这种方法论去拆解我这个广告呢？

首先我先拆解一下他的品牌。他的品牌大家能想到什么？能想到吃的，能想到古法，因为他毕竟是一个阿胶品牌。而且古法还能想到传承，而且这个古法呢会给我一种贵气的感觉，因为他毕竟是阿胶嘛，贵气、贵族的感觉。这是我根据品牌联想出来的词。

那我就要看他的视频广告和短视频传播，我能给你想到哪些？我脑子里蹦出了两个字，叫做**短剧**。如果我能把这些内容拍成像短剧一样的、可以在短视频平台传播的广告片，是不是很好？

于是我就诞生了一个想法：他既然贵族了，既然又是古法了，那我时代我要锚定一个古代。还宫，他是一个传承，他就意味着这个方法一直流传至今，曾经是贵族享用的食品，那他现在应该不是了，应该是我们每一个人都能享用的美味。

那我要在这里加一个普通人。因为我如果把视角锚定在了古代的皇宫，我能拿用一些后宫嫔妃吗？可是谁会跟一个后宫嫔妃来共情呢？但是你能不能跟一个古代的普通人共情？能。这个普通人我锚定的是**宫女**。

但是我光有一个宫女去看到娘娘享用了这种美食，她去追捧，这个故事不好看呀，完全不好看呀。我毕竟是要拍给现代人看吧，我的目标的用户我是现代人呀，我是2026年的人呀。所以我得让他们对这个东西感兴趣。

于是我就用上了这个"短剧"。短剧里面有什么？还能联系出来什么东西呀？**重生、穿越、职场打工人**。那我把这个加在这个故事里就行了。

所以我要讲一个现代2026的职场打工人，穿越回到了古代，他还是职场打工人，是一个宫女。我苦呀！他决定这一次重生了，我要夺回我失去的一切。什么呢？夺回自己的时间，夺回自己曾经在工作压力下失去的美貌。于是他们就开始找方法，什么方法呢？那要皇宫里的娘娘正在吃阿胶呀！于是他就开始了解到底阿胶是什么。我这个故事就出来了。

而且我现在整个一个故事，它是一个短片。这无论放在哪个短视频平台传播，别人都误以为他是短剧。那会不会去点开我的主页往下看？他肯定会点开，然后就跳转着我的购买链接了。所以我的一个用户触达的这个目的，我就达到了。

我想用这种短剧、用这种联想方式，还有一个原因：我既然有一个短剧类型的片子，那我能不能说服甲方，你给我拍一个系列的片子？你把这个重生系列，你拍一整个系列，你把它真正像短剧一样，把IP人物做出来。那其实你整个品牌连IP形象都有了，而且还能一直拍下去。这样呢，我的客单价也会提高，我的业务量也会增加。

所以这就是用了故事联想的方式去做了一个广告片子。所以无论你是写广告、写宣传片，还是做活动创意策划，故事的方法论都是通用的。而这些我都会在零基础写作26讲，以及活动策划IP，以及宣传片文案写作的课程里面讲给大家，后续我也会继续分享的。
